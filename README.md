# ARVEX v3 — локальный профиль и сохранение прогресса

## Добавлено
- Первое приветствие и создание локального профиля: имя + username.
- Username с правилами: 3–20 символов, латиница, цифры и подчёркивание.
- Профиль, демо-баланс, XP, уровень, позиции и история сохраняются в localStorage браузера.
- При следующем открытии на том же браузере данные восстанавливаются.
- Изменение имени через кнопку профиля.

## Открытие
Открой `index.html` в браузере или размести папку на Netlify. Интернет нужен для TradingView и Binance API.

## Важно
Это локальный профиль, не настоящая регистрация: данные не синхронизируются между телефонами и браузерами и могут быть удалены очисткой данных браузера. Для настоящих аккаунтов, восстановления доступа и синхронизации понадобится сервер и база данных. Демо-сделки не являются реальными биржевыми операциями. Не финансовая рекомендация.

## Обновление: сохранение и Академия
- Сделки, баланс, история, XP и уровень сохраняются сразу после каждого действия (и при сворачивании вкладки).
- Исправлено отсутствие окна создания профиля в `index.html`, из-за которого `app.js` падал с ошибкой и не загружал сохранённые данные.
- Академия: 3 урока (`lessons.js`) и тест после каждого. XP начисляется один раз: +20 за урок и +20 за сданный тест (минимум 2 из 3 правильных).
- Прогресс Академии хранится в localStorage вместе с остальным состоянием.

## Фьючерсный симулятор (учебный)
- Плечо 1x–20x. «Маржа» — собственные средства, размер позиции = маржа × плечо.
- Ликвидация: поддерживающая маржа 0,5% от размера. Цена ликвидации показывается до входа и в открытой позиции. При ликвидации теряется только маржа (без XP).
- Funding Rate: учебное значение 0,01% за 8 часов от размера позиции, начисляется пропорционально времени. LONG платит, SHORT получает.
- Позиции, открытые до этого обновления, считаются как 1x.
- Цены обновляются раз в 15 секунд, ликвидации проверяются при каждом обновлении цен.

## Android APK (Capacitor)
- Файлы Capacitor лежат в папке `mobile/` (чтобы не мешать публикации сайта на Netlify).
- Сборка: GitHub → Actions → **Build APK** → Run workflow. `app.zip` больше не нужен: workflow сам копирует файлы сайта в `mobile/www`, создаёт Android-проект (`npx cap add android`), синхронизирует и собирает **debug APK** (устанавливается на телефон без ключей подписи).
- APK появится в Artifacts запуска (`arvex-debug-apk`). Галочка «Опубликовать APK в GitHub Releases» создаёт релиз со ссылкой для скачивания.
- Для публикации в Google Play понадобится подписанный release-билд с keystore (добавим отдельным шагом).
- Приложение: `app.arvex.trading`, название ARVEX. Данные пока хранятся локально в WebView на устройстве.
