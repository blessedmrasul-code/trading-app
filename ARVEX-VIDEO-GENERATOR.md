# ARVEX Video Generator

A manual GitHub Actions workflow that requests four short anime scenes from the public LTX-Video Hugging Face Space, then joins them with FFmpeg into a 30-second vertical 720x1280 MP4.

## Run
1. Open the repository Actions tab.
2. Select **ARVEX 30s video**.
3. Choose the default branch and press **Run workflow**.
4. When the run finishes, download the **ARVEX-TikTok-30s-720p** artifact.

The workflow uses a public shared Hugging Face Space. Its queue, free capacity, API and availability are controlled by that service and can change. Four scene generations are sequential, so success and timing are not guaranteed. GitHub-hosted standard runners are free for public repositories; this does not make the external video model unlimited.

The final 3-second card includes the exact Latin brand spelling **ARVEX**. No real trading or income claims are shown.
