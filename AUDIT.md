## Проверено и замечаний нет
- 320, 360, 412 px: 5 экранов без горизонтального скролла и ошибок консоли.
- Битое хранилище (не JSON, null, массив, NaN-поля, чужие активы, XSS в имени и фото) не роняет приложение.
- Ввод суммы (пусто, 0, минус, текст, 1e309) не ломает баланс; двойное закрытие позиции безопасно.
- Без сети график показывает помеченные демо-свечи; недоступный localStorage не роняет приложение.
- Все скрипты из `index.html` есть в `sw.js` и в `mobile/build-web.js` (в APK ничего не потеряется).
- Нет `eval`, `document.write`, дублей `id`; пользовательский текст экранируется, фото профиля проверяется по формату.
- Облако: пароль не хранится, токены в localStorage; на новом пустом устройстве побеждает облако.

## Не исправлено / рекомендации
1. Работа с реальным Supabase и на реальных телефонах не проверялась (только имитация сервера и эмуляция экрана).
2. Платная подписка и проверка оплаты обязательно на сервере: любая проверка в JS обходится.
3. Ключи Supabase anon публичны по дизайну; безопасность держится на RLS из `backend/supabase.sql`.
4. Данные Binance публичные, ограничений по частоте запросов нет, но при росте числа пользователей лучше кэшировать через свой сервер.
